# java-calculator-precourse

# 기능 요구 사항

1. 빈 문자열 입력 -> 0 반환
2. 숫자 1개 입력 -> 그 숫자 반환
3. 쉼표 구분 입력 ("1,2" -> 3) 
4. 콜론 구분 입력 ("1:2:3" -> 6)
5. 기본 구분자 혼합 ("1,2:3" -> 6)
6. 커스텀 구분자 ("//;\n1;2;3" -> 6)
7. 커스텀 구분자 ("//|\n1|2|3" -> 6)

# IllegalArgumentException이 발생되는 경우

8. 잘못된 형식 ("//\n2|4|6") -> 12
9. 구분자로 끝나는 문자열 ("1,2,")
10. 음수 포함 ("-1,2")
11. 숫자 아닌 값 포함 ("a,1")
